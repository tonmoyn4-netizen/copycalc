# My Productivity App

Smart calculator + text converter. Pure React + Vite, no API key needed.

## Run locally
```
npm install
npm run dev
```

## Build
```
npm run build
```

## Deploy to Netlify
1. Push this folder to a GitHub repo (replace your old repo contents with these files).
2. netlify.com → Add new site → Import from GitHub → pick repo.
3. Build command: `npm run build`, Publish directory: `dist` (already set in netlify.toml).
4. Deploy. No environment variables required.
